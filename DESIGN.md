# Aether Design Language

Calm neutral surfaces, clear hierarchy, compact native controls. Original Aether
identity: an open triangular A crossed by a rising plane. `assets/aether.svg` is
the canonical colored mark; `assets/aether.icon` is its native vector counterpart.
Assets are original project geometry, not Apple, Zen or Helium artwork.

Setup uses a 4 DIP spacing base, 8 DIP controls and 12 DIP cards. Browser chrome
keeps Helium's existing native metrics except for profile-driven toolbar padding.
Native browser colors are generated by Chromium ThemeService; setup tokens do
not replace the browser's semantic color provider or accessibility system.

System appearance and neutral accent are defaults. Presets and a local color
picker choose opaque RGB accents. Primary actions and focus rings use contrasting
neutral text/surfaces; colored selection borders have a second shape/checked cue.

System typography: Segoe UI Variable / Segoe UI on Windows, system-ui elsewhere.
No remote fonts. Setup primary actions are at least 42 DIP high. Layout wraps
below 760 DIP and cards stack below 540 DIP. Zoom and OS scaling remain native.

Hover feedback is 100 ms. Welcome uses one 700 ms entrance, then stays still.
Reduced-motion removes all setup animations/transitions. Forced-colors retains
visible controls. Radios, fieldsets, semantic headings, focus movement, live
progress and error announcements provide keyboard/screen-reader structure.

The setup preview shows local layout/appearance choices immediately; the native
browser changes atomically at Finish. Presets currently affect Home/Profile
button visibility only. Workspaces, command palette and extra settings taxonomy
are not represented as working features.

Visual layout, contrast under arbitrary accents, high DPI, native touch sizing
and screen-reader behavior still require browser/OS verification.
